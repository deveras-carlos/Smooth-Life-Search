\begin{abstract}
This document describes the current implementation of Smooth-Life-Search as
a mathematical and algorithmic system. The project contains a literal
two-dimensional SmoothLife-style simulator coupled to an optimization
objective, and a higher-level Adaptive Grid Smooth Life Search controller
(AGSLS). The current AGSLS controller is phase-driven: it runs a SmoothLife
field, detects active basins, optionally uses local quadratic surrogates,
evaluates off-grid trust-region candidates from a persistent sample archive,
and remaps the active search box. The report emphasizes what the repository
implements now, not a proposed redesign. A final checklist summarizes
redesign questions that this implementation naturally raises.
\end{abstract}

\section{Notation and Coordinate Conventions}

The implementation currently supports two-dimensional objectives. Let the
active search box be
\begin{equation}
B =
\begin{bmatrix}
\ell_x & u_x \\
\ell_y & u_y
\end{bmatrix},
\qquad
w_x = u_x - \ell_x,\quad w_y = u_y - \ell_y.
\label{eq:bounds}
\end{equation}
The SmoothLife grid has height $H$ and width $W$. Grid row and column indices
are denoted by $(r,c)$ with $0 \le r < H$ and $0 \le c < W$. The pixel center
world coordinate is
\begin{equation}
x(c;B) = \ell_x + \frac{c + 1/2}{W} w_x,
\qquad
y(r;B) = \ell_y + \frac{r + 1/2}{H} w_y.
\label{eq:grid-to-world}
\end{equation}
The corresponding point is
\begin{equation}
p_{r,c}(B) =
\begin{bmatrix}
x(c;B) \\
y(r;B)
\end{bmatrix}.
\label{eq:pixel-point}
\end{equation}
The field value at grid cell $(r,c)$ is $F_{r,c} \in [-1,1]$. Objective values
are cached in $Y_{r,c}$ and the Boolean evaluated mask is $M_{r,c}$.
Unevaluated objective values are stored as NaN.

\section{SmoothLife Field Model}

\subsection{Initial Field}

At reset, the implementation draws a signed field with a random component,
a sinusoidal spatial bias, Gaussian noise, and a damped central patch:
\begin{equation}
F^0_{r,c}
= \mu
+ U_{r,c}
+ 0.20 \sin(3\pi \rho_r)\cos(2\pi \chi_c)
+ \eta_{r,c},
\label{eq:initial-field}
\end{equation}
where $U_{r,c} \sim \mathcal{U}(-0.75,0.75)$, $\eta_{r,c}$ is Gaussian noise,
$\rho_r,\chi_c \in [-1,1]$, and a central square is multiplied by $0.25$.
The final field is clipped to the configured interval
$[\texttt{field\_floor}, \texttt{field\_ceiling}]$, normally $[-1,1]$.

\subsection{Vitality}

The implementation interprets values near zero as alive. Vitality is
\begin{equation}
V(F)_{r,c} = \clip(1 - |F_{r,c}|, 0, 1).
\label{eq:vitality}
\end{equation}
An alive mask for basin detection is later defined as
\begin{equation}
A_{r,c}(\tau) = \mathbf{1}\{|F_{r,c}| \le \tau\},
\label{eq:alive-mask}
\end{equation}
where the AGSLS default alive core threshold is $\tau=0.30$.

\subsection{Anti-Aliased Kernels and Convolution}

The disk and ring kernels are normalized, anti-aliased radial masks. For a
radius $R$ and anti-alias radius $a$, the smooth disk indicator is
\begin{equation}
D_R(d) =
\begin{cases}
1, & d \le R-a,\\
\frac{1}{2}\left(1+\cos\left(\pi\frac{d-(R-a)}{2a}\right)\right),
& R-a < d < R+a,\\
0, & d \ge R+a.
\end{cases}
\label{eq:smooth-disk}
\end{equation}
The disk kernel is
\begin{equation}
K_{\mathrm{in}}(i,j)
= \frac{D_{R_{\mathrm{in}}}(\sqrt{i^2+j^2})}
{\sum_{i,j} D_{R_{\mathrm{in}}}(\sqrt{i^2+j^2})},
\label{eq:disk-kernel}
\end{equation}
and the ring kernel is
\begin{equation}
K_{\mathrm{out}}(i,j)
= \frac{\clip(D_{R_{\mathrm{out}}}(\sqrt{i^2+j^2})
-D_{R_{\mathrm{in}}}(\sqrt{i^2+j^2}),0,\infty)}
{\sum_{i,j}\clip(D_{R_{\mathrm{out}}}(\sqrt{i^2+j^2})
-D_{R_{\mathrm{in}}}(\sqrt{i^2+j^2}),0,\infty)}.
\label{eq:ring-kernel}
\end{equation}
Circular convolution is used, so the field domain is toroidal:
\begin{equation}
(G*K)_{r,c} =
\sum_{i,j} G_{(r-i)\bmod H,(c-j)\bmod W}K_{i,j}.
\label{eq:periodic-convolution}
\end{equation}
The inner and outer fills are therefore
\begin{equation}
N = V(F)*K_{\mathrm{in}},
\qquad
M = V(F)*K_{\mathrm{out}}.
\label{eq:inner-outer}
\end{equation}
In code, these are named \code{inner_fill} and \code{outer_fill}.

\subsection{SmoothLife Transition}

The implementation uses a smooth logistic step
\begin{equation}
\sigma(x;c,\alpha)=\frac{1}{1+\exp(-4(x-c)/\max(\alpha,10^{-12}))}.
\label{eq:sigmoid}
\end{equation}
Birth and death thresholds are mixed according to inner fill:
\begin{equation}
\operatorname{mix}(a,b,N)
= a(1-\sigma(N;0.5,\alpha_m)) + b\sigma(N;0.5,\alpha_m).
\label{eq:mix}
\end{equation}
The lower and upper outer-fill thresholds are
\begin{equation}
L = \operatorname{mix}(b_{\ell},d_{\ell},N),
\qquad
U = \operatorname{mix}(b_h,d_h,N),
\label{eq:thresholds}
\end{equation}
where the default parameters are approximately
$b_{\ell}=0.278$, $b_h=0.365$, $d_{\ell}=0.267$, $d_h=0.445$,
$\alpha_n=0.028$, and $\alpha_m=0.147$.
The canonical SmoothLife target vitality is
\begin{equation}
T_V = \clip\left(\sigma(M;L,\alpha_n)
\left(1-\sigma(M;U,\alpha_n)\right),0,1\right).
\label{eq:target-vitality}
\end{equation}

\subsection{Objective-Coupled Signed Target}

The simulator preserves field polarity and stores life as low magnitude. Let
$O_{r,c}\in[0,1]$ be the objective support field. If objective coupling is
disabled, or if the run mode is simulation, the life support is simply
$T_V$. Otherwise:
\begin{equation}
C_O = (1-\lambda) + \lambda O,
\qquad
T_L = \clip(T_V C_O,0,1),
\label{eq:life-support}
\end{equation}
where $\lambda=\texttt{objective\_coupling}$. The signed target state is
\begin{equation}
T_F = \operatorname{polarity}(F)\,(1-T_L).
\label{eq:signed-target}
\end{equation}
The polarity is $\sign(F)$, with exact zeros resolved from the four-neighbor
sign and then defaulting to $+1$ if still unresolved.

\subsection{Field Update, Diffusion, and Drift}

The four-neighbor periodic Laplacian is
\begin{equation}
\Delta F_{r,c}
=\frac{1}{4}\left(
F_{r-1,c}+F_{r+1,c}+F_{r,c-1}+F_{r,c+1}
\right)-F_{r,c}.
\label{eq:laplacian}
\end{equation}
For continuous time mode, the update before drift is
\begin{equation}
\tilde F^{t+1}
= F^t + dt\,(T_F^t-F^t)+\kappa\Delta F^t.
\label{eq:continuous-update}
\end{equation}
For the default discrete mode, it is
\begin{equation}
\tilde F^{t+1}
=(1-dt)F^t+dt\,T_F^t+\kappa\Delta F^t.
\label{eq:discrete-update}
\end{equation}
Here $\kappa=\texttt{diffusion}$.

In search mode, AGSLS can enable objective drift. Let
\begin{equation}
g = \nabla O = (g_y,g_x),
\qquad
\hat g = \frac{g}{\max(\|g\|_2,10^{-15})}.
\label{eq:support-gradient}
\end{equation}
For each grid cell, the implementation samples the field at the departure
location
\begin{equation}
(r',c')=(r,c)-s\hat g_{r,c},
\label{eq:departure-point}
\end{equation}
where $s=\texttt{objective\_drift\_strength}$. Bilinear interpolation produces
$F_{\mathrm{adv}}(r',c')$. The drift correction is clipped:
\begin{equation}
F^{t+1}
= \clip\left(\tilde F^{t+1}
+ \clip(F_{\mathrm{adv}}-\tilde F^{t+1},-\delta,\delta),
F_{\min},F_{\max}\right),
\label{eq:drift}
\end{equation}
where $\delta=\texttt{objective\_drift\_clip}$.

\section{Objective Evaluation and Cache Model}

\subsection{Lazy Pixel Evaluation}

At every SmoothLife step, the simulator evaluates a limited number of
unexplored pixel centers. The default limit is
\code{evaluations_per_step = 16}. For a selected set of rows and columns
$\mathcal{E}$, the simulator computes
\begin{equation}
Y_{r,c} = f(p_{r,c}(B)),
\qquad
M_{r,c}=1,
\qquad
(r,c)\in\mathcal{E}.
\label{eq:pixel-evaluation}
\end{equation}
The grid cache is local to the active bounds. When AGSLS remaps to a new
box, the objective cache is cleared and bootstrap exploration evaluates new
pixels in the new box.

\subsection{Best Records}

The simulator maintains:
\begin{itemize}[nosep]
\item \code{best_point}, \code{best_value}: global best over the run;
\item \code{local_best_point}, \code{local_best_value}: best since the last remap;
\item \code{box_best_point}, \code{box_best_value}: best in the current grid box.
\end{itemize}
For minimization, $y_a$ is better than $y_b$ if
\begin{equation}
y_a < y_b - \tau_{\mathrm{best}},
\label{eq:better-min}
\end{equation}
and for maximization if
\begin{equation}
y_a > y_b + \tau_{\mathrm{best}}.
\label{eq:better-max}
\end{equation}
The default tolerance is zero.

\subsection{Subpixel Candidate}

When enabled, the best evaluated pixel can produce a subpixel candidate. If
a full $3\times3$ neighborhood around the best pixel is evaluated, the code
fits
\begin{equation}
q(\Delta c,\Delta r)
= a + b\Delta c + h\Delta r + d\Delta c^2
+ e\Delta c\,\Delta r + g\Delta r^2.
\label{eq:subpixel-quadratic}
\end{equation}
The stationary point solves
\begin{equation}
\begin{bmatrix}
2d & e\\
e & 2g
\end{bmatrix}
\begin{bmatrix}
\Delta c_*\\
\Delta r_*
\end{bmatrix}
=-
\begin{bmatrix}
b\\h
\end{bmatrix}.
\label{eq:subpixel-stationary}
\end{equation}
The offset is accepted only if the Hessian has the right definiteness and
is well behaved. It is clamped to $[-0.5,0.5]^2$. If the joint fit is not
available, the implementation falls back to axis-wise parabolic offsets.
If confirmation is enabled, the off-grid subpixel point is actually evaluated
before updating the best record.

\section{Objective Support, RBF Guidance, and Uncertainty}

\subsection{Sampled Normalization}

Let $\mathcal{I}=\{(r,c):M_{r,c}=1\}$ be the evaluated cells in the current
grid cache. If no cells are evaluated, the objective support is neutral:
\begin{equation}
O_{r,c}=0.5.
\label{eq:neutral-objective}
\end{equation}
For minimization, evaluated values are normalized as
\begin{equation}
\bar O_{r,c}
= \frac{Y_{\max}-Y_{r,c}}{\max(Y_{\max}-Y_{\min},10^{-12})},
\qquad (r,c)\in\mathcal{I}.
\label{eq:min-support}
\end{equation}
For maximization,
\begin{equation}
\bar O_{r,c}
= \frac{Y_{r,c}-Y_{\min}}{\max(Y_{\max}-Y_{\min},10^{-12})}.
\label{eq:max-support}
\end{equation}
The configured gamma sharpens the field:
\begin{equation}
O_{r,c}=\clip(\bar O_{r,c},0,1)^\gamma.
\label{eq:gamma-support}
\end{equation}
Unevaluated cells remain neutral in sampled mode.

\subsection{RBF/Softmin Guidance}

In AGSLS commit and exploitation phases, the objective guidance mode is set
to \code{rbf}. The top $K$ evaluated samples are selected by objective value.
Let their normalized grid coordinates be $z_i\in[0,1]^2$ and sampled support
values be $s_i\in[0,1]$. For every grid coordinate $z$:
\begin{equation}
k_i(z)=\exp\left(-\frac{\|z-z_i\|_2^2}{2\sigma^2}\right),
\qquad
\omega_i=\exp\left(\frac{s_i-\max_j s_j}{T}\right).
\label{eq:rbf-weights}
\end{equation}
The predicted support is
\begin{equation}
\hat s(z)
= \frac{\sum_i k_i(z)\omega_i s_i}
{\sum_i k_i(z)\omega_i},
\label{eq:rbf-prediction}
\end{equation}
when the denominator is nonzero. The confidence is
\begin{equation}
\rho(z)=\clip\left(\frac{\sum_i k_i(z)\omega_i}{\max_i \omega_i},0,1\right).
\label{eq:rbf-confidence}
\end{equation}
The guided support starts as
\begin{equation}
O_{\mathrm{guided}}(z)
= 0.5(1-\rho(z))+\rho(z)\hat s(z).
\label{eq:guided-support}
\end{equation}
For unevaluated cells only, an uncertainty bonus can be added:
\begin{equation}
O_{\mathrm{guided}}(z)
\leftarrow
O_{\mathrm{guided}}(z)
+ u\,\rho(z)\bigl(1-O_{\mathrm{guided}}(z)\bigr).
\label{eq:uncertainty-bonus}
\end{equation}
Evaluated cells are then restored to their sampled support values, so real
objective observations remain authoritative.

\subsection{Support Field and EMA}

The support field used by basin detection is the product of vitality and
objective support:
\begin{equation}
S = V(F)O.
\label{eq:support-field}
\end{equation}
AGSLS can smooth support over time with an exponential moving average:
\begin{equation}
S_{\mathrm{ema}}^t
= (1-\alpha)S_{\mathrm{ema}}^{t-1}+\alpha S^t.
\label{eq:support-ema}
\end{equation}
When $\alpha=0$, the raw support field is used.

\section{Pixel Scoring}

\subsection{Exploration Score}

The default exploration score for unevaluated pixels is
\begin{equation}
E_{\mathrm{explore}}
=\frac{1}{2}V(F)+\frac{1}{2}\clip(1-|T_F|,0,1).
\label{eq:exploration-score}
\end{equation}
At each SmoothLife step, the engine evaluates the unevaluated cells with
largest score.

\subsection{Exploitation Score}

The current late-stage score is used by the SmoothLife engine but AGSLS now
also has a trust-region path. If no objective signal is present, exploitation
falls back to Equation~\eqref{eq:exploration-score}. Otherwise:
\begin{equation}
U_O = \clip(1 - 2|O-0.5|,0,1)
\label{eq:objective-uncertainty}
\end{equation}
and
\begin{equation}
E_{\mathrm{exploit}}
= \clip(U_O S + 0.25 B_{\partial},0,1.25),
\label{eq:exploitation-score}
\end{equation}
where $B_{\partial}$ marks four-neighbor boundaries of the high-support set.

\section{Basin Detection}

\subsection{Core and Envelope Masks}

Given support $S$, alive mask $A$, and quantile $q$, the basin detector forms
\begin{equation}
\theta_{\mathrm{core}}=\operatorname{quantile}(S,q),
\qquad
C = A \cap \{S\ge\theta_{\mathrm{core}}\}.
\label{eq:basin-core}
\end{equation}
It also forms a looser envelope threshold
\begin{equation}
q_{\mathrm{env}} = \max(0.50,q-\Delta q),
\qquad
\theta_{\mathrm{env}}=\operatorname{quantile}(S,q_{\mathrm{env}}),
\qquad
G = A\cap\{S\ge\theta_{\mathrm{env}}\}.
\label{eq:basin-envelope}
\end{equation}
Core pixels are clustered with a small DBSCAN-like rule in grid coordinates.
For each accepted core cluster, the connected component of the envelope mask
that contains the core is selected and optionally dilated.

\subsection{Basin Features}

For a basin envelope $\Omega$ and core $\Omega_c$, support mass is
\begin{equation}
m(\Omega)=\sum_{(r,c)\in\Omega_c} S_{r,c}.
\label{eq:support-mass}
\end{equation}
The support-weighted world centroid is
\begin{equation}
\bar p(\Omega)=
\frac{\sum_{(r,c)\in\Omega_c}S_{r,c}p_{r,c}}
{\sum_{(r,c)\in\Omega_c}S_{r,c}}.
\label{eq:basin-centroid}
\end{equation}
Alive density is
\begin{equation}
d_A(\Omega)=\frac{1}{|\Omega|}\sum_{(r,c)\in\Omega} A_{r,c}.
\label{eq:alive-density}
\end{equation}
If evaluated pixels exist in the envelope, the basin records its best
objective value, best point, best objective support, and mean objective
support. The objective score used by the basin object is
\begin{equation}
o(\Omega)=0.7\,\max_{\Omega\cap\mathcal{I}} O
+0.3\,\mean_{\Omega\cap\mathcal{I}} O.
\label{eq:basin-objective-score}
\end{equation}
If no evaluated pixels exist, this score is set to $0.25$.

\section{AGSLS Controller}

\subsection{Phases}

AGSLS runs against a required evaluation budget $N_{\max}$. The budget
fraction is
\begin{equation}
\phi = \frac{N_{\mathrm{eval}}}{N_{\max}}.
\label{eq:budget-fraction}
\end{equation}
The phase is
\begin{equation}
\operatorname{phase}(\phi)=
\begin{cases}
\mathrm{exploration}, & \phi < \phi_{\mathrm{explore}},\\
\mathrm{commit}, & \phi_{\mathrm{explore}}\le \phi < \phi_{\mathrm{commit}},\\
\mathrm{exploitation}, & \phi \ge \phi_{\mathrm{commit}}.
\end{cases}
\label{eq:phase-rule}
\end{equation}
Current defaults are $\phi_{\mathrm{explore}}=0.05$ and
$\phi_{\mathrm{commit}}=0.70$, although the CLI examples often override
\code{commit_fraction} to $0.90$.

\subsection{Phase Parameter Application}

Exploration uses sampled objective behavior and disables drift. Commit uses
RBF support, uncertainty bonus, support EMA, and objective drift. Exploitation
also uses RBF support but with a smaller RBF scale, lower drift, and no
uncertainty bonus by default.

\subsection{Basin Ranking}

For each decision round, AGSLS first runs SmoothLife steps and accumulates a
persistence map. At each persistence step, the active high-support alive mask
is
\begin{equation}
P^t_{r,c}
= \mathbf{1}\left\{A_{r,c}=1,\ S_{r,c}\ge
\operatorname{quantile}(S,q)\right\}.
\label{eq:persistence-step}
\end{equation}
The normalized persistence score is
\begin{equation}
\Pi_{r,c} = \frac{1}{T}\sum_{t=1}^{T}P^t_{r,c}.
\label{eq:persistence}
\end{equation}
For basin $\Omega$, stability is the mean persistence over its scoring mask:
\begin{equation}
s_{\Pi}(\Omega)=\mean_{(r,c)\in\Omega_{\mathrm{score}}}\Pi_{r,c}.
\label{eq:stability}
\end{equation}
In commit, the combined score is
\begin{equation}
R_{\mathrm{commit}}(\Omega)
= w_m\frac{m(\Omega)}{m_{\max}}
+ w_d d_A(\Omega)
+ w_s s_{\Pi}(\Omega)
+ w_o o(\Omega)
- w_a\frac{|\Omega|}{|\Omega|_{\max}}.
\label{eq:commit-ranking}
\end{equation}
The current default weights are
$w_m=1.35$, $w_d=1.20$, $w_s=1.00$, $w_o=0.45$, and $w_a=0.15$.
In exploitation, the ranking gives a bonus to basins containing the incumbent:
\begin{equation}
R_{\mathrm{exploit}}(\Omega)
= 2\,\mathbf{1}\{\text{incumbent in envelope}\}
+ o_{\mathrm{best}}(\Omega)
+0.25\frac{m(\Omega)}{m_{\max}}
+0.25s_{\Pi}(\Omega).
\label{eq:exploit-ranking}
\end{equation}

\begin{algorithm}
\caption{AGSLS run loop}
\begin{algorithmic}[1]
\Require Objective $f$, initial bounds $B_0$, budget $N_{\max}$, zoom limit $Z_{\max}$
\State Reset SmoothLife engine on $B_0$
\State Initialize empty persistent sample archive
\State Run exploration until $\phi_{\mathrm{explore}}N_{\max}$
\While{evaluations $<\phi_{\mathrm{commit}}N_{\max}$ and zooms $<Z_{\max}$}
    \State Run one commit decision round
\EndWhile
\While{evaluations $<N_{\max}$ and zooms $<Z_{\max}$}
    \State Run one exploitation decision round
\EndWhile
\State \Return best point, best value, snapshots, zoom events, diagnostics
\end{algorithmic}
\label{alg:agsls-run}
\end{algorithm}

\begin{algorithm}
\caption{One AGSLS decision round}
\begin{algorithmic}[1]
\Require Phase $\rho\in\{\mathrm{commit},\mathrm{exploitation}\}$
\State Apply phase-specific SmoothLife runtime parameters
\State Run SmoothLife for phase-specific step count, accumulating persistence
\State Archive all finite evaluated grid samples
\State Detect and rank basins
\State Select top-ranked basin $\Omega$ if any
\If{trust region enabled}
    \State Run trust-region acquisition batch around selected center
\ElsIf{$\rho=\mathrm{exploitation}$}
    \State Run exploitation valley-tracking fallback
\EndIf
\State Compute phase zoom/remap bounds
\If{bounds make strict finite progress}
    \State Remap SmoothLife field to new bounds and clear grid cache
    \State Bootstrap evaluation in new box and archive samples
    \State Record accepted zoom event
\Else
    \State Record deferred decision; return true if trust-region probes spent budget
\EndIf
\end{algorithmic}
\label{alg:decision-round}
\end{algorithm}

\section{Commit Surrogate}

\subsection{Weighted Quadratic Model}

The commit surrogate fits a quadratic model from evaluated grid samples inside
or near the selected basin:
\begin{equation}
q(z) = \beta_0+\beta_1z_x+\beta_2z_y+\beta_3z_x^2+\beta_4z_xz_y+\beta_5z_y^2,
\qquad z\in[0,1]^2.
\label{eq:commit-quadratic}
\end{equation}
Coordinates are normalized inside the active box:
\begin{equation}
z = \frac{p-B_{\min}}{B_{\max}-B_{\min}}.
\label{eq:normalized-point}
\end{equation}
For maximization, the target values are sign-converted so the surrogate always
models a minimization target:
\begin{equation}
t_i =
\begin{cases}
Y_i, & \text{minimize},\\
-Y_i, & \text{maximize}.
\end{cases}
\label{eq:sign-converted-target}
\end{equation}
Targets are normalized to $[0,1]$. The least-squares problem is
\begin{equation}
\hat\beta
=\argmin_{\beta}
\sum_i w_i\left(\Phi(z_i)^\top\beta-\tilde t_i\right)^2
+\lambda\|\beta_{1:5}\|_2^2,
\label{eq:weighted-ls}
\end{equation}
where
\begin{equation}
\Phi(z)=
\begin{bmatrix}
1 & z_x & z_y & z_x^2 & z_xz_y & z_y^2
\end{bmatrix}^\top.
\label{eq:quadratic-design}
\end{equation}
The weights combine objective quality, support, and proximity to the basin
reference point:
\begin{equation}
w_i = 0.25 + Q_i + \lambda_S S_i
+0.50\exp\left(-\frac{\|z_i-z_{\mathrm{ref}}\|_2^2}{2(0.20)^2}\right).
\label{eq:commit-weights}
\end{equation}

\subsection{Trust Checks and Center}

The Hessian of the quadratic is
\begin{equation}
H =
\begin{bmatrix}
2\beta_3 & \beta_4\\
\beta_4 & 2\beta_5
\end{bmatrix},
\qquad
g =
\begin{bmatrix}
\beta_1\\
\beta_2
\end{bmatrix}.
\label{eq:quadratic-hessian}
\end{equation}
The candidate optimum is
\begin{equation}
z_*=-H^{-1}g.
\label{eq:quadratic-optimum}
\end{equation}
The surrogate is accepted only if there are enough samples, all coefficients
are finite, the design condition number is below the configured maximum, the
Hessian is positive definite, the Hessian condition is acceptable, and
$z_*\in[0,1]^2$. The predicted improvement must be strictly positive by
default:
\begin{equation}
\Delta_{\mathrm{pred}} =
\tilde t_{\mathrm{basin-best}} - q(z_*) > 0.
\label{eq:predicted-improvement}
\end{equation}

\subsection{Valley-Aware Widths}

If the surrogate is accepted, AGSLS can shape commit widths using the surrogate
eigenbasis. Let $H=V\Lambda V^\top$ with eigenvalues sorted from low curvature
to high curvature. The current implementation expands along the low-curvature
direction and shrinks across the high-curvature direction:
\begin{equation}
h_{\mathrm{eig}}
= |V|^\top h_{\mathrm{axis}},
\qquad
h'_{\mathrm{eig},0}=\eta_{\mathrm{valley}}h_{\mathrm{eig},0},
\qquad
h'_{\mathrm{eig},1}=\eta_{\mathrm{cross}}h_{\mathrm{eig},1}.
\label{eq:valley-widths}
\end{equation}
The adjusted axis-aligned half-widths are
\begin{equation}
h'_{\mathrm{axis}} = |V|h'_{\mathrm{eig}}.
\label{eq:axis-widths}
\end{equation}
Defaults are \code{commit_surrogate_valley_expand = 1.25} and
\code{commit_surrogate_cross_shrink = 0.65}.

\begin{algorithm}
\caption{Commit surrogate fit}
\begin{algorithmic}[1]
\Require Basin $\Omega$, active bounds $B$, evaluated cache $(Y,M)$
\State Build candidate mask from basin envelope; pad if too few samples
\State Keep finite evaluated samples inside the mask
\If{sample count $<$ minimum}
    \State reject with \code{insufficient_samples}
\EndIf
\State Optionally keep at most max samples by quality, support, and proximity
\State Normalize points into $[0,1]^2$ and sign-convert targets
\State Solve weighted ridge quadratic least squares
\State Compute Hessian, eigenvalues, and stationary point
\If{fit is nonfinite, ill-conditioned, nonconvex, or outside bounds}
    \State reject with diagnostic reason
\EndIf
\If{predicted improvement $\le$ threshold}
    \State reject with \code{no_predicted_improvement}
\EndIf
\State accept surrogate center and diagnostics
\end{algorithmic}
\label{alg:commit-surrogate}
\end{algorithm}

\section{Trust-Region Archive and Acquisition}

\subsection{Persistent Sample Archive}

The grid cache is reset on remap, so AGSLS maintains a separate archive
\begin{equation}
\mathcal{A}=\{(p_i,y_i)\}_{i=1}^{n_A}.
\label{eq:archive}
\end{equation}
Grid samples are archived before and after decision rounds. Direct off-grid
trust-region probes are also archived. Duplicate points are rejected by exact
floating-point hexadecimal keys. This is intentionally separate from the grid
cache: direct probes update best records but do not create fake evaluated
pixels.

\subsection{Trust Region Bounds and State}

For a center $c$ and radius fraction $r$, the trust-region box is
\begin{equation}
T(c,r;B)=
\prod_{j\in\{x,y\}}
\left[
\max(\ell_j,c_j-rw_j),
\min(u_j,c_j+rw_j)
\right].
\label{eq:trust-bounds}
\end{equation}
The center is chosen from, in order:
\begin{enumerate}[nosep]
\item exploitation: global best if inside the active bounds;
\item commit: accepted commit surrogate point if valid;
\item basin best;
\item basin centroid;
\item global best;
\item active-box center.
\end{enumerate}
The initial radius is the configured initial radius fraction, clipped by the
basin width when a basin exists:
\begin{equation}
r_0 = \min\left(r_{\mathrm{init}},
\max\left(r_{\min},1.25\max_j\frac{0.5\,w_{\Omega,j}}{w_j}\right)\right).
\label{eq:initial-radius}
\end{equation}

\subsection{Archive Quadratic}

The trust-region surrogate fits the same quadratic family as
Equation~\eqref{eq:commit-quadratic}, but using archive samples inside
$T(c,r;B)$. It accepts the fit if enough archive samples are present and the
weighted design is finite and well-conditioned. Unlike the commit surrogate,
the archive surrogate may still be accepted when the stationary point is not
usable; in that case it can predict candidate values but does not contribute a
surrogate optimum candidate.

\subsection{Candidate Pool}

The deterministic candidate pool contains:
\begin{itemize}[nosep]
\item the trust-region center;
\item anchor points such as global best, basin best, basin centroid, and
commit surrogate point;
\item interpolation points between center and surrogate optimum when present;
\item coordinate, diagonal, and surrogate-eigenvector stencil points at
scales $0.25$, $0.5$, and $1.0$;
\item deterministic golden-angle scattered points.
\end{itemize}
Candidates outside both the active bounds and the trust-region box are
discarded.

\subsection{Acquisition Score}

For candidates $x_k$, the trust-region acquisition score is
\begin{equation}
A(x_k)
= P(x_k) + 0.35 I(x_k)
+\lambda_{\mathrm{sup}} S_B(x_k)
+\lambda_{\mathrm{unc}} U_A(x_k).
\label{eq:acquisition}
\end{equation}
Here $P$ is normalized predicted quality from the archive quadratic,
$I(x_k)$ is a predicted-improvement indicator, $S_B(x_k)$ is the SmoothLife
support sampled at the candidate's grid cell, and $U_A$ is archive uncertainty:
\begin{equation}
U_A(x)
= \clip\left(
\frac{1}{0.25}
\min_{(p_i,y_i)\in\mathcal{A}}
\left\|
\frac{x-p_i}{w}
\right\|_2,
0,1
\right).
\label{eq:archive-uncertainty}
\end{equation}
Exact duplicates receive score $-\infty$. Commit uses a larger uncertainty
weight than exploitation.

\subsection{Radius Adaptation}

After evaluating the selected candidates, the radius is adapted:
\begin{equation}
r^+ =
\begin{cases}
\min(1,\alpha_{\mathrm{expand}}r), & \text{if any strict improvement occurs},\\
\max(r_{\min},\alpha_{\mathrm{shrink}}r), & \text{otherwise}.
\end{cases}
\label{eq:radius-update}
\end{equation}
The default expansion factor is $1.4$ and the default shrink factor is $0.5$.

\begin{algorithm}
\caption{Trust-region acquisition batch}
\begin{algorithmic}[1]
\Require Phase $\rho$, selected basin $\Omega$, active bounds $B$
\If{trust region disabled or no budget}
    \State return no-op diagnostics
\EndIf
\State Archive all finite current grid samples
\State Select center $c$ and anchors from phase, basin, surrogate, and incumbent
\State Resolve current radius fraction $r$
\State Fit archive quadratic using samples inside $T(c,r;B)$
\State Build deterministic candidate pool
\State Rank candidates by acquisition score
\If{$\rho=\mathrm{exploitation}$}
    \State Try the local high-signal stencil first, then acquisition-ranked candidates
\EndIf
\For{candidate in selected order until batch budget is spent}
    \If{candidate is duplicate or outside bounds}
        \State skip
    \EndIf
    \State Evaluate objective at candidate
    \State Archive sample
    \State Update global, local, and box best if strictly improved
\EndFor
\State Expand radius on improvement, shrink otherwise
\State Record compact diagnostics
\end{algorithmic}
\label{alg:trust-region}
\end{algorithm}

\section{Exploitation Valley-Tracking Fallback}

When trust-region acquisition is disabled, exploitation can run a smaller
valley-tracking mechanism. It fits an incumbent-centered or basin-centered
quadratic surrogate from the current grid cache, extracts the low-curvature
eigenvector, and probes symmetrically along that tangent.

If $v_{\min}$ is the eigenvector associated with the smallest positive
curvature, the candidate points are
\begin{equation}
x_{\pm}=x_{\mathrm{best}}\pm \alpha\, v_{\min}\odot w,
\label{eq:valley-probes}
\end{equation}
where $w$ are current box widths and $\alpha$ decays geometrically. Strict
improvements update the global best. These probes are direct objective
evaluations and do not mark grid pixels as evaluated.

\begin{algorithm}
\caption{Exploitation valley-tracking fallback}
\begin{algorithmic}[1]
\Require Basin $\Omega$, current bounds $B$
\If{disabled or no probe budget}
    \State return no-op diagnostics
\EndIf
\State Fit incumbent-centered surrogate; fall back to basin surrogate
\State Extract lowest-positive-curvature tangent
\While{probe budget remains and step fraction is above minimum}
    \State Evaluate symmetric candidates around current best
    \State Accept the best strict improvement, if any
    \State Decay the step fraction
\EndWhile
\State Return diagnostics
\end{algorithmic}
\label{alg:valley-tracking}
\end{algorithm}

\section{Zooming, Remapping, and Numerical Floors}

\subsection{Commit Bounds}

Commit zooms are conservative. The initial target width comes from the
selected basin envelope, padded by \code{commit_zoom_padding}. The minimum
commit width is
\begin{equation}
w_{\min}^{\mathrm{commit}}
= \max(\eta_{\mathrm{commit}}w,\ w_{\mathrm{pixel}}),
\label{eq:commit-floor}
\end{equation}
where $\eta_{\mathrm{commit}}=\texttt{commit\_min\_shrink\_fraction}$ and
$w_{\mathrm{pixel}}=(w_x/W,w_y/H)$. The target width is
\begin{equation}
w_{\mathrm{target}}
=\min\left(w,\max(w_{\mathrm{basin-padded}},w_{\min}^{\mathrm{commit}})\right).
\label{eq:commit-target-width}
\end{equation}
If the global best is inside the current bounds, commit bounds are expanded
as needed to retain it with padding.

\subsection{Exploitation Bounds}

Exploitation uses the global best as the center whenever it lies inside the
active bounds. The target width is
\begin{equation}
w_{\mathrm{target}}^{\mathrm{exploit}}
= \eta_{\mathrm{exploit}}w.
\label{eq:exploit-target-width}
\end{equation}
There is no current-pixel floor in exploitation. If floating-point
representability prevents the requested width, the code falls back to the
nearest representable interval around the center.

\subsection{Strict Progress}

A remap is accepted only if all bounds are finite, every upper bound is
strictly greater than its lower bound, and the new area is strictly smaller:
\begin{equation}
\operatorname{area}(B^+) < \operatorname{area}(B).
\label{eq:strict-progress}
\end{equation}
This protects against nonfinite, degenerate, or no-op zooms.

\subsection{Remap Behavior}

On remap, the field is interpolated into the new bounds, the objective cache
is cleared, local and box best records reset, dynamics fields are refreshed,
bootstrap exploration evaluates new pixels, support EMA is reset, and a
snapshot is captured.

\begin{algorithm}
\caption{Remap and archive flow}
\begin{algorithmic}[1]
\Require New bounds $B^+$
\State Archive finite samples from current grid cache
\State Interpolate SmoothLife field from old bounds to $B^+$
\State Clear objective values, objective support, and evaluated mask
\State Reset local and box best records
\State Refresh SmoothLife dynamics
\State Bootstrap by evaluating top-vitality pixels in $B^+$
\State Reset support EMA and improvement trackers
\State Archive newly bootstrapped samples
\State Capture forced snapshot
\end{algorithmic}
\label{alg:remap}
\end{algorithm}

\section{Diagnostics and Test Coverage}

Each accepted zoom event records:
\begin{itemize}[nosep]
\item phase, zoom reason, evaluation counts, budget fraction, shrink ratio;
\item selected basin score, envelope, area, support mass, density, stability,
objective score, and incumbent-in-envelope flag;
\item commit surrogate status, sample count, condition, predicted point, and
predicted value when present;
\item trust-region status, candidate count, evaluations spent, improvement
count, center/radius before and after, best before and after, remap flag, and
surrogate diagnostics;
\item valley-tracking diagnostics when the fallback is used.
\end{itemize}
Run metadata includes phase counts, zoom cycles, decision trace, trust-region
events, and sample archive size.

The current regression smoke tests assert:
\begin{itemize}[nosep]
\item Rosenbrock seed $7$, budget $6400$, reaches best value $<10^{-2}$;
\item Ackley seed $7$, budget $12800$, reaches exactly the origin and zero;
\item Rosenbrock seed $7$, budget $30000$, prompt-style command shape,
reaches best value $<10^{-11}$ with trust-region improvements;
\item disabling trust region restores the zoom-first path and leaves no
trust-region events;
\item Ackley, Sphere, and Rastrigin seed $7$, budget $30000$, prompt-style
command shape, still reach exactly zero at the origin.
\end{itemize}

\section{Current Strengths}

\begin{itemize}
\item The SmoothLife mechanism is still the base field mechanism: objective
guidance modulates support and drift but does not replace the core transition.
\item The AGSLS phase structure is explicit and easy to reason about.
\item The persistent archive fixes the earlier problem that off-grid probes
or pre-remap samples were lost as soon as the grid cache reset.
\item Trust-region acquisition lets the algorithm improve precision without
depending only on finer grid remaps.
\item The commit surrogate and trust-region surrogate are simple quadratic
models, which makes diagnostics interpretable.
\item Exact regression tests protect the current desirable behavior on
Ackley, Sphere, Rastrigin, and Rosenbrock.
\end{itemize}

\section{Current Limitations}

These are analysis notes, not additional current mechanisms.

\begin{itemize}
\item The implementation is still two-dimensional. Most formulas generalize,
but basin detection, visualization, and grid assumptions are 2D-specific.
\item The archive is a simple list with exact duplicate keys. This is clear
but can become expensive for large budgets, many seeds, or higher dimensions.
\item Trust-region acquisition is single-region per decision round. It does
not maintain a portfolio of competing basins.
\item Quadratic surrogates are interpretable and cheap, but curved valleys,
periodic landscapes, and multimodal surfaces may need richer local models.
\item Commit trust-region probes currently update the incumbent but do not
normally override commit zoom geometry; this is deliberate after experiments,
but it means trust and zoom control are not fully unified.
\item The SmoothLife field and trust-region archive are coupled only through
support sampling and basin proposals. There is no learned feedback from
trust-region success back into field dynamics beyond best records and later
support fields.
\item Evaluation allocation is heuristic: fixed SmoothLife step counts,
fixed trust-region batch sizes, and fixed phase fractions.
\item Diagnostics are rich but ad hoc dictionaries rather than typed event
records.
\end{itemize}

\section{Redesign Planning Checklist}

The following questions are the most important ones for planning a redesign:

\begin{enumerate}
\item Should SmoothLife remain a dense field over a fixed grid, or become a
proposal density over an adaptive point cloud?
\item Should AGSLS keep explicit exploration, commit, and exploitation phases,
or should phase behavior emerge from budget and improvement signals?
\item Should there be a multi-basin portfolio of trust regions rather than a
single selected basin per decision round?
\item Should the surrogate stay quadratic, or should the archive support RBF,
Gaussian-process-like, ensemble, or local polynomial alternatives?
\item Should zoom/remap become optional visualization/context maintenance
rather than a core optimization action?
\item Should objective support influence only evaluation choice, or also
modify life/death thresholds in a mathematically controlled way?
\item Should the sample archive become the central data structure, with grid
caches treated as temporary render/evaluation views?
\item Should diagnostics become typed dataclasses with stable schema so
experiments can be compared across redesigns?
\item Should budget allocation be adaptive, for example based on expected
improvement, trust-region success rate, basin entropy, or archive uncertainty?
\item Should the next redesign target 2D performance only, or prepare the
algorithm for higher-dimensional objectives?
\end{enumerate}

    \State Blend field toward SmoothLife transition target with diffusion
    \State Apply objective-gradient drift if enabled

    \State Score unexplored pixels and evaluate top batch

    \State Capture snapshot when configured

\caption{Current basin detection}
\begin{algorithmic}[1]
\State Compute core threshold from support quantile
\State Compute looser envelope threshold
\State Build alive high-support core mask
\State Cluster core pixels with DBSCAN-like grid rule
\State Label connected components of envelope mask
\For{each core cluster}
    \State Select envelope component containing the cluster
    \State Dilate envelope
    \State Compute support mass, centroid, bbox, density, objective features
    \State Record incumbent containment and basin best
\EndFor
\State Return basins sorted by support mass
\end{algorithmic}
\label{alg:basin-detection}
\end{algorithm}

\State Evaluate objective on selected points
\State Store values in grid cache and mark evaluated mask

\section{Closing Summary}

The current project is best understood as three layers. The bottom layer is
a literal signed SmoothLife field that produces alive structures and support
patterns. The middle layer turns objective observations into grid support,
detects basins, and manages remaps. The top layer, AGSLS, now uses a persistent
sample archive and trust-region acquisition to improve points outside the
grid cache while keeping SmoothLife as the basin proposal mechanism.

For redesign, the most consequential question is whether the sample archive
and trust-region acquisition should become the primary optimizer, with
SmoothLife acting as a structured proposal prior, or whether SmoothLife should
remain the primary search object and the archive should stay auxiliary.
